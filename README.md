# Awesome DESIGN.md（中文版）

把一份 DESIGN.md 复制进你的项目，跟 AI 说"照这个风格帮我做一个页面"，就能生成视觉风格统一、档次在线的高质量 UI。

每一份都带真正的设计深度——包括分析过的设计模式、设计令牌（token）和设计规则——产出的是高质量 UI，不是浮于表面的模仿。


## 什么是 DESIGN.md？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) 是 Google Stitch 提出的新概念：一份纯文本的设计系统文档，AI 读了它就能生成风格一致的 UI。

它就是个 markdown 文件。不用导 Figma，不用写 JSON Schema，不用装任何工具。往项目根目录一扔，任何 AI 编码代理或 Google Stitch 立刻明白你的界面该长什么样。Markdown 是 LLM 读得最好的格式，无需解析、无需配置。

| 文件 | 谁来读 | 定义什么 |
|------|-------------|-----------------|
| `AGENTS.md` | 编码代理 | 项目怎么构建 |
| `DESIGN.md` | 设计代理 | 项目该长什么样、什么气质 |

**本仓库提供开箱即用的 DESIGN.md 文件**，全部从真实网站提取。

## 每份 DESIGN.md 里有什么

每个文件遵循 [Stitch DESIGN.md 格式](https://stitch.withgoogle.com/docs/design-md/specification/)，并做了扩展：

| # | 章节 | 内容 |
|---|---------|-----------------|
| 1 | 视觉主题与氛围 | 情绪、密度、设计哲学 |
| 2 | 色板与色彩角色 | 语义化命名 + 色值 + 功能角色 |
| 3 | 排版规则 | 字体家族，完整层级表 |
| 4 | 组件样式 | 按钮、卡片、输入框、导航（含各状态） |
| 5 | 布局原则 | 间距比例、栅格、留白哲学 |
| 6 | 层深与海拔 | 阴影体系，表面层级 |
| 7 | 该做与不该做 | 设计护栏与反模式 |
| 8 | 响应式行为 | 断点、触控目标、折叠策略 |
| 9 | 代理提示词指南 | 速查色卡，即用提示词 |

每个站点包含：

| 文件 | 用途 |
|------|---------|
| `DESIGN.md` | 设计系统本体（给 AI 读的） |
| `preview.html` | 可视化目录：色板、字号阶梯、按钮、卡片 |
| `preview-dark.html` | 同款目录的暗色表面版 |

### 如何使用


1. 把某个站点的 `DESIGN.md` 复制到你的项目根目录
2. 告诉你的 AI 照这个风格来。
